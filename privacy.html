← 청약 체크로 돌아가기

개인정보처리방침

시행일 2026-11-09 · 웹사이트와 앱(Android·iOS)에 같이 적용돼요

1. 누가 운영하나요

청약 체크는 청약 체크 운영자가 운영하는 개인 서비스예요. 정부·LH·SH·서울시와 관계없어요. 문의: GitHub Issues (https://github.com/DioneLee/cheongyak-check/issues)

2. 어떤 정보를 어디에 저장하나요

입력한 생년월일·소득·자산·결혼 여부 같은 진단 조건, 넣은 공고, 관심 공고(★), 필터는 이 기기에만 저장돼요(브라우저 저장소, 앱은 앱 저장 공간). 운영자의 서버로 보내지 않고, 운영자는 이 정보를 볼 수 없어요.

3. 회원가입 · 분석 도구

회원가입이 없고, 방문자 분석·광고 도구도 쓰지 않아요. 앱은 관심 공고 마감 알림을 기기 안에서만 예약해요(알림을 허용한 경우).

4. 밖으로 보내는 정보

  • AI로 공고문 읽기: 공고문 PDF를 올리고 읽기 버튼을 누를 때만 그 공고문 파일만 Google Gemini로 보내요(설정에 내 Gemini 키를 넣었으면 Google로 바로, 아니면 이 서비스의 중계 서버를 거쳐요 · 중계 서버는 내용을 저장하지 않아요). 내 진단 조건은 보내지 않아요.
  • 통근 길찾기: 버튼을 누를 때만 단지 주소와 회사 주소를 OpenStreetMap 위치 검색으로 보내요.
  • 공고 목록·상세는 이 서비스의 공개 파일에서 받아요(내 정보를 보내지 않음).

5. 정보 출처

공고 정보: 마이홈포털·LH 공공데이터 API, SH·서울 청년안심주택 공고 게시판(제목·날짜·원문 링크만), 롯데건설 엘리스(제목·링크). 판정은 참고용이고 모집공고문 원문이 우선이에요(이용약관).

6. 지우는 방법

웹: 브라우저의 사이트 데이터를 지우면 함께 지워져요. 앱: 앱을 삭제하면 함께 지워져요.
